# Stocks Forecast

A small **React and Express** web app that projects long-term portfolio value. 

User can select up to four scenarios and compare them:
- What happens if I don't invest ?
- What happens if I invest once and forget about it ?
- What happens if I invest the same amount each year ?
- What happens if I invest a growing amount each year ?

You can select the assumptions you want:
- roi
- inflation rate
- tax rate
- investment rate
- salary

## Disclaimer

This tool is for **education and planning experiments only**. It simplifies taxes, returns, and inflation. Consult a qualified professional before making financial decisions.
